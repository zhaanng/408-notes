**结点的黑高** bh：从某个结点开始，到其**下一个叶子结点**的简单路径上的黑色结点的数目（**起点不算**）
![[Pasted image 20260520221104.png]]

红黑树的黑高 是其对应的B树的高度。

红黑树的==性质==：
	1、==平衡性==：高的子树 **不超过** 矮的子树高度的 2倍。
		==从根结点到叶子结点的最长路径长度 不大于最短路径长度的2倍==
		从根结点到叶子结点的最短的路径长度：黑高bh
		从根结点到叶子结点的最长的路径长度：2\*bh
			最短：没有红结点，全部是黑结点。共有包括叶子结点在内的 **bh+1**个结点，因此共有bh个路径长度。
			最长：每个黑结点都分出一个红结点，共有包括叶子结点在内的 **2\*bh+1**个结点，因此共有2\*bh个路径长度。
			==路径长度\==边的个数==
	2、黑高为bh的红黑树 结点个数n，当该红黑树没有红色结点时 结点**==个数最少==**，该红黑树就是一个高度为bh的满二叉树，n>=2^bh -1
		黑高为bh的红黑树 结点个数==n>=2^bh -1==
		n>=2^bh -1
		n+1>=2^bh
		log(n+1)>=bh>=h/2
		h/2<=log(n+1)------>==h<=2log(n+1)==

红黑树的==应用==：
	AVL：平衡性限制的太严格了。不适用于动态查找
	红黑树：平衡性的限制放宽了。相较于avl树 **更适合动态查找**

2、Linux CPU调度——》完全公平调度

红黑树**操作**：
	查找（因为和二叉平衡树的一致，就不讲了） 插入 删除 

RBT的插入操作：一棵红黑树上插入结点z
==性质：左根右 根叶黑 不红红 黑路同==

插入过程：
1、新建一个结点z 把待插入的数据放到z中，按照RBT插入过程，把z插入到红黑树中。——》满足了 **顺序性**
2、结点z的**初始颜色**：==红色==
	~~（1）黑色：不行，一定破坏 **\"黑路同"**，每次插入之后都得进行调整~~
	（2）红色：该结点做**根结点**时破坏 \"**根叶黑**"，当结点的**父亲也是红色**时破坏”**不红红**“，其他情况不破坏性质。
	所以选红色。
结点结构：
	![[Pasted image 20260525211145.png]]


父亲和叔叔都是红色时的==解决思路==：
	![[Pasted image 20260525211323.png]]
	![[Pasted image 20260525211259.png]]
	插入：**先还原成B树，再进行拆分，拆成合适的红黑树**
		最后依据现象总结成：**父一代变成黑色，父父代变成红色**
	这个就是下面3种情况中的第2种情况 破坏不红红 的父亲叔叔都是红色的情况


3、新结点插入后，有哪几种情况？分三种情况。
	（1）z是红色，且是空树插入z，z做根结点，此时破坏“根叶黑”——》**直接把z赋值为黑色**
	（2）z是红色，插入后，z的父亲也是红色——》**见下面的分类讨论**
	（3）不破坏性质，不需要变化


==（2）z是红色，插入后，z的父亲也是红色==：
	破坏“不红红”性质 具体的分类及其调整：
		**可以确定**的是：
			新插入的结点z 红色的
			z的父亲结点p 红色的 parent
			z的爷爷结点g 黑色的 grandparent
		**不能确定**的是： uncle
			z的叔叔结点u u为空结点（即叶子结点）是**黑色的**/u存在时，一定是**红色**——》随着调整的进行，如果**向上循环调整**了，**新的z**（原来的==**爷爷结点g**==，因为它调整后**变红**了）的叔叔结点u存在时 **可能为红，可能为黑**

uncle分两种情况：

一、叔叔是==**红色**==的
	p和u变黑。g变红。如果g的父亲是黑色，调整结束。
	**如果g的父亲是红的，g及其父亲又破坏“不红红”了**——》继续**向上循环调整**：把g看成z，把g的父亲看成p，再继续判断满足哪种调整情况。
	如果g一直是红的，那么当g为根结点时，就可以结束了，把根结点变黑。
	![[Pasted image 20260526082534.png]]

二、叔叔是==**黑色**==的（因为设计循环向上调整，后面的调整过程中，如果叔叔是黑色的，叔叔不一定是==null==的）
	这种需要通过**旋转**来解决
	**调整过程中不涉及到u，不需要考虑u了**
	仿照AVL树的插入失衡的4种情况，针对p和z的方向分4类

分为两类：
	1、直线型 RR LL
	2、折线型 RL LR

==RR==：p是g的右孩子，z的p的右孩子
先对g左旋，g变红，p变黑。
**父父左**
![[Pasted image 20260526092203.png]]

==RL==：p是g的右孩子，z的p的左孩子
先对p右旋，再对g左旋，g变红，z变黑。
**父右父父左**
![[Pasted image 20260526092155.png]]

==LL==：先对g右旋，g变红，p变黑

==LR==：先对p左旋，再对p右旋，g变红，z变黑

#include<stdio.h>
#include<stdlib.h>
#define RED 1
#define BLACK 0
typedef struct RBTNode
{
	int data;
	struct RBTNode* l;
	struct RBTNode* r;
	int color;
	struct RBTNode* pa;//双亲结点
}RBTNode,*RBTree;
RBTNode* CreatNode(int k,RBTNode* parent,RBTNode* left,RBTNode* right)
{//创建一个新结点
	RBTNode* s=(RBTNode*)malloc(sizeof(RBTNode));
	//if(s==NULL)
	s->data=k;
	s->color=RED;//新创建的结点是红色
	s->pa=parent;
	s->l=left;
	s->r=right;
	return s;
}
//在以root为根的树中，对x进行右旋
RBTNode* RightRotate(RBTree root,RBTNode* x)
{
	//指针y指向x的左孩子
	RBTNode* y=x->l;
	RBTNode* fx=x->pa;//x的父亲

	//x的左孩子指针 指向yr
	x->l=y->r;
	if(y->r!=NULL)y->r->pa=x;

	//y的右孩子指针 指向x
	 y->r=x;//y的右孩子变成x
	 x->pa=y;
	//处理y和fx的关系 y的父亲会变成fx
	y->pa=fx;
	if(fx==NULL)root=y;//如果旋转之前x是根结点 旋转之后y是根结点
	else
	{//fx如果存在 其孩子由x变为了y
		if(fx->l==x)fx->l=y;
		else fx->r=y;
	}
	return root;
}
//在以root为根的树中，对x进行左旋
RBTNode* LeftRotate(RBTree root,RBTNode* x)
{
	//指针y指向x的右孩子
	RBTNode* y=x->r;
	RBTNode* fx=x->pa;//x的父亲

	//x的右孩子指针 指向yl
	x->r=y->l;
	if(y->l!=NULL)y->l->pa=x;

	//y的左孩子指针 指向x
	 y->l=x;//y的左孩子变成x
	 x->pa=y;
	//处理y和fx的关系 y的父亲会变成fx
	y->pa=fx;
	if(fx==NULL)root=y;//如果旋转之前x是根结点 旋转之后y是根结点
	else
	{//fx如果存在 其孩子由x变为了y
		if(fx->l==x)fx->l=y;
		else fx->r=y;
	}
	return root;
}
RBTree Fixup(RBTree root,RBTNode* z)
{//在以root为根的树中，z及其父亲破坏了不红红 需要调整。
	RBTNode* p=z->pa;//z的父亲
	RBTNode* g=NULL;//z的爷爷结点
	RBTNode* u=NULL;//z的叔叔结点
	while(p!=NULL&&p->color==RED)
	{//父亲存在 且为红色 需要继续调整
		//此时爷爷一定存在
		g=p->pa;//爷爷结点
		if(p==g->r)//p是g的右孩子
		{
			u=g->l;//叔叔不一定存在
			if(u!=NULL&&u->color==RED)
			{//叔叔是红色
				p->color=BLACK;
				u->color=BLACK;
				g->color=RED;
				//g做新的要调整的结点
				z=g;//z指向新的罪魁祸首
				p=g->pa;
			}
			else
			{//叔叔为黑色------》RR/RL
				if(z==p->r)//RR
				{
					root=LeftRotate(root,g);
					p->color=BLACK;
					g->color=RED;
				}
				else//RL
				{
					root=RightRotate(root,p);
					root=LeftRotate(root,g);
					z->color=BLACK;
					g->color=RED;
				}
				break;
			}
		}
		else
		{
			u=g->r;
			if(u!=NULL&&u->color==RED)
			{//叔叔是红色
				p->color=BLACK;
				u->color=BLACK;
				g->color=RED;
				//g做新的要调整的结点
				z=g;//z指向新的罪魁祸首
				p=g->pa;
			}
			else
			{//叔叔是黑色---->LL/LR
				if(z==p->l)//LL
				{
					root=RightRotate(root,g);
					p->color=BLACK;
					g->color=RED;
				}
				else//LR
				{
					root=LeftRotate(root,p);
					root=RightRotate(root,g);
					z->color=BLACK;
					g->color=RED;
				}
				break;

			}
		}
		
	}
	if(p==NULL)root->color=BLACK;//如果是向上调整到根结点做新的z,也就是p为NULL 跳出循环， 那就需要把根结点赋黑
	return root;
}
RBTree Insert(RBTree root,int k)
{
	//空树插入
	if(root==NULL)
	{
		root=CreatNode(k,NULL,NULL,NULL);
		root->color=BLACK;//根结点颜色是黑色
		return root;
	}
	//非空树插入
	//1.执行 BST的插入过程：找k的父亲结点，如何插入k所在的结点
	RBTNode* z=root;
	RBTNode* zp=NULL;//查找过程中一直指向z的父亲
	while(z!=NULL)
	{
		zp=z;
		if(k<z->data)z=z->l;
		else z=z->r;
	}
	//2.创建结点
	z=CreatNode(k,zp,NULL,NULL);
	//3.插入
	if(z->data<zp->data)zp->l=z;
	else zp->r=z;

	//z的颜色是红色的 并且z有父亲zp zp是红色 会破坏不红红 需要调整
	if(zp->color==RED)
	{
		root=Fixup(root,z);//z及其父亲 破坏不红红 调整
	}
	return root;
}

RBTNode* FindNode(RBTree root,int k)
{//递归的查找
	if(root==NULL)return NULL;
	if(root->data==k)return root;

	if(k<root->data)return FindNode(root->l,k);
	else return FindNode(root->r,k);

}
RBTree DE_Fixup(RBTree root,RBTNode* x,RBTNode* p)
{//x可能是空的 p可能是空的----》但是x和p不可能同时为空
	RBTNode* w=NULL;//删除y之后，w是x的兄弟结点

	//x是黑色并且x不是根结点
	while(x!=root&&(x==NULL||(x!=NULL&&x->color==BLACK)))
	{//(3)删除的结点y黑 顶替y位置的x也黑 并且x不是根结点---》p一定存在
		if(x==p->r)
		{//1. x在右边 w在左边
			w=p->l;//w一定不为NULL
			//情况c）w为红色
			if(w->color==RED)
			{
				root=RightRotate(root,p);//对p右旋
				w->color=BLACK;
				p->color=RED;
				w=p->l;
			}
			//到此处，x的兄弟w一定是黑色的，此时一定是情况a/b
			//b)w的两个孩子都是黑色
			if((w->l==NULL||(w->l!=NULL&&w->l->color==BLACK))&&(w->r==NULL||(w->r!=NULL&&w->r->color==BLACK)))
			{
				w->color=RED;
				x=p;//p变成新的要调整的结点
				p=x->pa;//继续循环向上调整
			}
			else
			{//a)w至少有一个红色孩子red
				RBTNode* red=NULL;
				//a.2)如果w的左孩子是黑的，red就是w的右孩子 LR
				if(w->l==NULL||(w->l!=NULL&&w->l->color==BLACK))
				{//LR
					red=w->r;
					root=LeftRotate(root,w);////对w左旋
					w->color=RED;
					red->color=BLACK;
					RBTNode* t=w;
					w=red;
					red=t;
				}
				//到此处，一定是LL情况
				red=w->l;
				w->color=p->color;
				root=RightRotate(root,p);//对p右旋
				red->color=BLACK;
				p->color=BLACK;
				break;//调整结束

			}
		}
		else
		{//2.x在左边 w在右边
			w=p->r;//w一定不为NULL
			//情况c）w为红色
			if(w->color==RED)
			{
				root=LeftRotate(root,p);//对p左旋
				w->color=BLACK;
				p->color=RED;
				w=p->r;
			}
			//到此处，x的兄弟w一定是黑色的，此时一定是情况a/b
			//b)w的两个孩子都是黑色
			if((w->l==NULL||(w->l!=NULL&&w->l->color==BLACK))&&(w->r==NULL||(w->r!=NULL&&w->r->color==BLACK)))
			{
				w->color=RED;
				x=p;//p变成新的要调整的结点
				p=x->pa;//继续循环向上调整
			}
			else
			{//a)w至少有一个红色孩子red
				RBTNode* red=NULL;
				//a.2)如果w的右孩子是黑的，red就是w的左孩子 RL
				if(w->r==NULL||(w->r!=NULL&&w->r->color==BLACK))
				{//RL
					red=w->l;
					root=RightRotate(root,w);////对w右旋
					w->color=RED;
					red->color=BLACK;
					RBTNode* t=w;
					w=red;
					red=t;
				}
				//到此处，一定是RR情况
				red=w->r;
				w->color=p->color;
				root=LeftRotate(root,p);//对p左旋
				red->color=BLACK;
				p->color=BLACK;
				break;//调整结束

			}

		}

	}
	//x是红色的情况-->情况（2）
	if(x!=NULL&&x->color==RED)x->color=BLACK;
	return root;

}
RBTree Delete(RBTree root,int k)
{
	if(root==NULL)
	{
		printf("空树，无法执行删除操作\n");
		return root;
	}
	//非空树删除k
	//1.找k所在的结点y
	RBTNode* y=FindNode(root,k);
	//特判k不存在
	if(y==NULL)
	{
		printf("该数据不存在，无法执行删除操作\n");
		return root;
	}
	//2.判断y的度是不是2 如果是转化成删除度为1/0的结点的情况
	if(y->l!=NULL&&y->r!=NULL)
	{
		//找y的中序遍历后继结点
		RBTNode* p=y->r;
		while(p->l!=NULL)
		{
			p=p->l;
		}
		//p就是y的后继结点
		y->data=p->data;
		//y指针指向真正被free的结点
		y=p;
	}
	//无论一开始的y的度是几，到此处，y的度一定是1/0
	RBTNode* p=y->pa;
	RBTNode* x=NULL;
	if(y->l!=NULL)x=y->l;
	else x=y->r;//x指向y唯一的孩子

	//x顶替y的位置：也就是y的父亲要成为x的父亲
	if(x!=NULL)x->pa=y->pa;//注意x可能是空的
	//如果p存在，x要成为p的孩子
	if(p!=NULL)
	{
		if(p->l==y)p->l=x;
		else p->r=x;
	}
	else
	{//如果p不存在，此时x就会成为根结点 
		root=x;
	}

	int yc=y->color;//记录y的颜色
	free(y);
	y=NULL;

	if(root==NULL)return root;//删除k之后 成为空树 ，不需要调整

	if(yc==BLACK)
	{
		root=DE_Fixup(root,x,p);//删除操作中的调整
	}

	return root;

}


void InOrder(RBTree root)
{
	if(root==NULL)return;

	InOrder(root->l);

	printf("%d ",root->data);//输出值
	if(root->color==RED)printf("RED ");
	else printf("BLACK ");//输出颜色
	if(root->pa!=NULL)printf("%d\n",root->pa->data);//输出父亲
	else printf("\n");

	InOrder(root->r);
}
int main()
{
	int n,k;
	scanf("%d",&n);
	RBTree root=NULL;
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&k);
		root=Insert(root,k);
	}

	InOrder(root);
	printf("-------------------------------\n");
	while(1)
	{
		scanf("%d",&k);
		if(k==-1)break;//结束删除
		root=Delete(root,k);
		InOrder(root);
		printf("-------------------------------\n");
	}
	return 0;
}
