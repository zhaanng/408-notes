###### 1、几种组网方式的区别

虚拟机结构原理：
	![[Pasted image 20260724094013.png]]

a. NAT方式
	宿主机里含有一个NAT服务（网络地址转换器，模拟成路由器，分LAN口 WAN口）
		a.1 宿主机里被安装了一个能够连接到NAT路由器的虚拟网卡（vmnet8），宿主机就是通过这个网卡**和虚拟机通信**
		a.2 虚拟机如果要访问外网，需要配置网关，网关的地址，必须是NAT路由器的LAN口IP（不能是Windows的vmnet8）、
		a.3 vmnet8这个网卡，是给宿主机用来访问虚拟机用的，一定不要配置网关和DNS，这个网卡不是为宿主机提供网络服务的
	假的路由器（软件），外网不能上，就看宿主机能不能上网了
b. host-only
	宿主机里安装了一个虚拟的交换机，为宿主提供了vmnet1的网卡，来连接到交换机上
	一旦虚拟机网卡连接到host-only，就意味着连接到了交换机，只能和vmnet1进行数据交换
	因为没有路由能力，虚拟机就无法访问外网
c. 桥接 Bridge
	虚拟机利用宿主机里实际的网卡，充当虚拟机的物理层，虚拟机利用自己独立的MAC地址，使用宿主机的物理层进行数据通信
	寝室里其他设备也可以直接访问到虚拟机

vmnet8:

这里的虚拟网卡vmnet8是给Windows的网卡，不是给虚拟机的。
**虚拟机内部还有一个虚拟网卡**。
所以 虚拟机要上外网，需要把网关配置成这个Windows  的LAN口IP。
就相当于把Windows和虚拟机之间的网络沟通的设置，用软件的方式给表现了，==把真正的Windows网卡硬件给虚拟化了==。
所以**这个虚拟网卡不能配置网关和DNS**，因为他代表的就是Windows的网卡能力，如果配置，会和真实的Windows网卡冲突，导致Windows无法连外网。



网关 Gateway：
![[Pasted image 20260724092432.png]]

==虚拟机没有网关==，因为网关是负责把内网的数据发送到外网上的地址口，而虚拟机不能真正的与外网连接，需要通过宿主机上的网卡来间接上网，所以没有网关，你不能把宿主机的网卡弄成虚拟机的网关。
###### 2. Vmware和Windows的数据互通

vmtools安装不了
wmtools就是vmware这个软件体供的一个插件，只适合在同一台机器上主机和虚拟机的访问
实验室的多态主机和服务器相连，这个插件无能为力
建议使用网络服务进行数据交换

C/S模型
	Client 和 Server          浏览器       百度服务器
	ssh 的远程登录协议

虚拟机里安装ssh的服务器进程
	a. 如何判断虚拟机里有没有这个服务，若没有就安装
		netstat -tuan 
			查看当前机器的服务(socket)链接状态
		每行都表示一条链接
			协议     接收缓存    发送缓存     本地地址     远程地址     状态
		只需要找本地地址中端口号为22的，只要有这一行就可以表示服务已经安装
	b. 如何安装ssh服务
		Ubuntu: 敲sshd的命令，自动提示你用什么命令来安装这个服务      sudo apt install openssh-server
		Centos: 搜索sshd的服务是什么软件，然后利用 sudo yum install xxxx

宿主机安装ssh的客户端进程：
	Mobaxterm
