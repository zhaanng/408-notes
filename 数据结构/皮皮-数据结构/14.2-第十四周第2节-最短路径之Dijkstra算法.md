两点之间的**距离**：
	无权图——路径所经过的**边的数目**。
	带权图——路径经过的**边的边权之和**。 

最短路径/距离：
	两点之间可能有多条路径，路径距离最短，称为最短路径/距离。

对于无向图：A——>B. B——>A的路径和最短路径**均相同**
对于有向图：A——>B. B——>A的路径和最短路径**不一定相同**

**证明==局部最优==（贪心）可以找到==整体最优路径==的算法**。

（1）单源最短路径：给定一个图，假设图中有n(n<100)个点，m条边，从给的起点s到剩下n-1个点的最短路径
	遍历图中n个点，就可以得到多源最短路径
	**Dijkstra**——单源最短路径算法——>**贪心**——>==**图中边权非负**==   (算法前提)

![[Pasted image 20260413195819.png]]
可以用**数组**记录答案:dist\[i]=x. s——>i (s到i) 的最短路径的长度(最短距离)是x
	特殊的有dist\[s]=0

s到剩下n-1个点的最短距离

第一个能确定最短路径的点 一定是离起点最近的点（邻接点），并且最短路径就是当前最近距离的路径

求到某点最短路径：
	起点到不直接邻接的点一定要经过邻接点，所以 起点 到 其他n-1个点任意一点 的最短距离一定是 **到邻接点距离中最小的距离**。

\------------------------------------
起点s到i的路径要缩短：==**通过引入新的中转点k**==

![[Pasted image 20260418104451.png]]

s——x——>i    （ **最开始默认最小值是直接到达的距离，后续遍历找中转点，再找更小的距离，如果有，更新最小距离** ）

s——y1——>k——y2——>i

==**y1+y2 < x**==

如果找不到新的k 则s——>i的最短路径就能确定下来。

依次确定s到剩下n-1个点的最短路径：
	每次 找到 **flag\==0&&dist值最小** 的点i，此时s到i的最短路径长度就是dist\[i]，不可能变得更短。
	因此此时i点的最短路径可以确定下来，然后用i点做中转点，更新其邻接点的最短路径。

![[Pasted image 20260413202351.png]]
	dist\[i] 表示起点s 到下标i点的 **最短距离**
	flag\[i] 表示该点的最短距离 **是否已经确认**
	pre\[i] 表示记录最短路径中s点要到该i点的 **前一个点**

#include<stdio.h>
#include<stdlib.h>
#include<string.h>
#define INF 10001
//n（<=100）个点,m条边的带权(边权<10000)无向图，求起点s到其他点的最短路径。//保证起点一定能走到其他点
//默认点的数据是0～～n-1
//邻接矩阵
int n,m,v;
int g[105][105];
int dist[105],flag[105],pre[105];
void Dijkstra(int s)//O(n*n)
{
	dist[s]=0;
	flag[s]=1;
	//先更新起点的邻接点 起点的邻接点 可以从起点直接到达
	for(int i=0;i<n;i++)
	{
		if(g[s][i]<INF)//i是x的邻接点
		{
			dist[i]=g[s][i];
			pre[i]=s;
		}
	}
	pre[s]=-1;//起点的上一个点是-1
	int k;//点
	int minn;//最小的dist
	for(int j=1;j<=n-1;j++)//执行n-1次 每次确定起点到一个点的最短距离
	{
		//还未确定最短距离的点中 dist值最小的点，其最短路径不可能再变小了
		k=-1;minn=INF;
		for(int i=0;i<n;i++)
		{
			if(flag[i]==0&&dist[i]<minn)
			{
				k=i;
				minn=dist[i];
			}
		
		}
		if(k==-1)
		{
			v=1;
			break;
		}
		//此时 k就是要找的点 也就是 k点的最短路径不会再更新了
		flag[k]=1;
		//用k做中转点 更新其邻接点
		for(int i=0;i<n;i++)
		{
			if(flag[i]==0&&dist[k]+g[k][i]<dist[i])
			{
				dist[i]=dist[k]+g[k][i];
				pre[i]=k;//记录路径
			}

		}

	}

}
int main()
{
	scanf("%d %d",&n,&m);
	//初始化
	for(int i=0;i<n;i++)
	{
		dist[i]=INF,pre[i]=-1;
		for(int j=0;j<n;j++)
		{
			g[i][j]=INF;
			if(i==j)g[i][j]=0;
		}
	}
	int x,y,w;
	for(int i=1;i<=m;i++)
	{
		scanf("%d %d %d",&x,&y,&w);
		g[x][y]=g[y][x]=w;
	}
	int s;
	scanf("%d",&s);
	Dijkstra(s);

	//输出s到每个点的最短路径及其长度
	if(v==1)
	{
		printf("起点无法到达所有的点\n");
	}
	for(int i=0;i<n;i++)
	{
		printf("%d到%d到最短路径长度是%d,其路径为：%d ",s,i,dist[i],i);
		int p=pre[i];
		while(p!=-1)
		{
			printf("%d ",p);
			p=pre[p];
		}
		printf("\n");
	}
	
	return 0;
}
