## ==磁盘分区：==

Linux ext2/ext3 布局 --》

分区内按功能划分不同部分：

1、引导块 Boot Block
2、超级块 Super Block
3、空闲空间管理
	位示图 Bitmap
	空闲链表
4、inode区  索引节点区
5、根目录
6、文件和目录

具体而言：

1、引导块
存放操作系统的启动引导程序。
	操作系统会安装到磁盘分区的某一个分区上，这个分区称为 系统盘
	系统盘里的引导块会存放内容，是操作系统的引导程序。
	这个引导程序很小，负责让CPU找到大部分操作系统的代码，
	还有 主动把操作系统内核读取加载到内存。
	大部分的操作系统的文件还是保存在磁盘的文件区域中。
	CPU不能自己直接去磁盘里找文件，必须依靠引导程序的引导。

固定大小：1个磁盘块  一般 4KB
大小：几乎可以忽略不计
特点：永远预留一块，绝大多数分区这里是空的

----
块：又称 簇，是操作系统读取磁盘的最小逻辑单元，类比 物理上磁盘划分的最小单位，扇区，硬件能读取的最小单元
	簇 和 扇区，二者大小可以相等，也可以不等。

2、超级块
保存当前这个分区（文件系统）的==全部全局信息==。
没有超级块，操作系统看不懂这个分区。

大小：一个磁盘块 4KB
大小：极小
特点：非常重要，超级块损坏会导致整个分区失效。所以系统会在分区多处存放超级块备份，但只有一个主超级块

-----
分区的全局信息，指的是分区层面的一些信息，比如 块大小、分区总容量、剩余空间、inode区在哪。。。

与此协调的是 inode，他负责记录单个 文件/目录 的信息，比如 文件大小、权限、文件的数据块地址。。。

也就是 两级分级管理，划分为 超级块 和 inode 两个级别。

3、空闲空间管理
记录分区内哪些磁盘块的空间没被占用

有两种实现方式：
	空闲链表
	位示图 Bitmap 空闲0 已占用1

4、inode区
索引节点区

每一个文件/文件夹对应 1个 inode
inode里存文件的 属性信息+数据块指针
但是 不存文件名

存放内容清单：
	文件大小
	创建时间、修改时间、访问时间
	文件权限（读、写、执行）
	文件所有者
	指向文件内容所在的数据块编号

文件名 存在 **目录项**（根目录、子目录）里面，不在 inode

5、根目录
根目录   /，反斜杠
一种特殊文件，即 目录文件

目录里面存放着一条条目录项：（文件名，对应的inode编号）
![[Pasted image 20260901170336.png]]

6、文件和目录（数据块区）
存放真正的文件内容数据
	txt文档里的文字
	图片、视频的二进制数据
	子目录的目录项内容
