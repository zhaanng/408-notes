拓扑排序：
	==把图中所有的点按照事情发生的先后顺序输出。
	**对于某一个点，只有前面所有的事都发生完了之后，它才可以发生**。
	如果有多个点同时满足可以发生的状态时，可以不在意顺序。==
	最后，我们把**点的入度数\==0** 作为 该点事情可以发生 的条件

拓扑排序需要的空间有：
	1、==邻接表==存储图，表的链表——》保存每个结点的所有==后继==结点
	2、ind\[] 数组，保存图的每个结点的==前驱的数目==。
		这个要==怎么实现==呢？参考邻接表存储每个结点的==所有后继结点==：
			输入表示边的两点 x y，Find(x) Find(y)处理得到 xi yi下标
			此时，==**xi 是 yi 的前驱，yi 是 xi 的后继**==
			通过xi下标找到当前处理的链表，把yi存取链表，yi即是xi的后继结点之一。
			因此，**我们可以通过 yi 找到要统计前驱数目的 ind\[]，因为有 xi 这个前驱，所以 ind\[yi]需要+1**
			这样就实现了在用处理边的时候完成对==每个结点的前驱的数目==的统计。

有向无环图(DAG) **Directed Acycline Graph**

==**树**是一种**特殊**的图，是一种**没有环的图**。==

七叉树的遍历：直接按照图的DFS或者BFS。

工程/项目
	可以用有向无环图进行工程/项目开发的管理

要把一个大的工程细分为很多子阶段，每个子阶段称为一个**活动**。
**用有向无环图的顶点表示活动，有向边表示活动之间的优先关系（依赖关系），就可以用图来表示工程的完整的过程**。用于表示工程的有向图称为**AOV网**。

==拓扑序列==：
	对于图中任意一点，**只有该点==入边==所连接的点所表示的事件都完成**后，才能完成该点所对应的事件，能完成所有事件的序列叫拓扑序列。

拓扑序列：就是一个顶点序列，完成该图所表示的工程的先后顺序。
拓扑序列：如果vi 到 vj之间有一条路径，那么vi 一定在vj之前完成。

用于得到拓扑序列的算法/思路，称为**拓扑排序**。

对于一个DAG图 拓扑序列不一定唯一。


拓扑序列的过程：
	引入一个**入度数组**（记录入度的数量）：ind\[i]
	执行n次循环：每次循环确定一个要做的活动：
		**开辟空间，专门存储入度为0的点，避免遍历**
		（1）**出栈**，得到一个当前**入度为0**的点，放到拓扑序列中；
		（2）然后把该点的出边邻接点的入度-1。如果邻接点的**入度减为0**了，就**入栈**。

Stack InitStack()
{
	Stack s=(SNode*)malloc(sizeof(SNode));

	s->next=NULL;
	return s;
}

Stack Push(Stack s,int k)
{
	Stack p=(SNode*)malloc(sizeof(SNode));

	p->data=k;

	s->next=p;

	if(s->next==NULL)
	{
		return 1;//空 
	}
	return 0;//非空 
 }

int GetTop(Stack s)
{
	if(IsEmpty(s)==0)
	{
		return s->next->data; 
	}
	else
	{
		return -1;
	}
}
//出栈 
Stack Pop(Stack s)
{
	if(IsEmpty(s)==0)
	{
		SNode* p=s->next;
		s->next=p->next;
		free(p);
		p=NULL;
	}
	return s;
}

{
	Stack s=InitStack();
	//先把一开始入度就为0的点入栈
	for(int i=1;i<=n;i++)
	{
		if(ind[i]==0)
		{
			s=Push(s,i);
		}
	}
	//执行n次循环，每次把一个点加入到拓扑序列中
	int j,z;
	ENode* p=NULL;
	for(int i=1;i<=n;i++)
	{
		//现在需要一个入度为0的点，但是如果此时栈空了，说明没有入度为0的点了，说明有环
		if(IsEmpty(s)==1)
		{
			break;//有环
		}
		j=GetTop(s);//先得到栈顶数据
		s=Pop(s);//出栈
		topo[++k]=g[j].data;//j加入到拓扑序列中 
		//把j的出边邻接点 入度-1
		p=g[j].first;
		while(p!=NULL)
		{
			z=p->adj;//z是j的一个出边邻接点
			ind[z]--;
			if(ind[z]==0)
			{
				s=Push(s,z);
			}
			p=p->next;//注意
		}
	}

}

{
	int data;// 存下标
	struct stackNode* next;
}stackNode,*stack;

{
	stack s = (stack)malloc(sizeof(stackNode));
	s->next = NULL;

	return s;
}

void pushStack(stack s,int index)
{
	stack newNode = (stack)malloc(sizeof(stackNode));
	newNode->data = index;
	newNode->next = s->next;
	s->next = newNode;
}

{
	if (s->next == NULL)
		return true;
	else
		return false;

	if (!isEmpty(s))
		return s->next->data;
	else

		cout << "栈为空，无法获取栈顶元素" << endl;
		return -1;
	}
		
}
// 出栈

{
	if (!isEmpty(s))
	{
		stackNode* p = s->next;

求**逆拓扑序列**：
	（1）先求拓扑序列，然后翻转。
	（2）维护出度，每次找出度为0的点，再把其入边邻接点的出度-1
	（3）建立**反向图**，反向图的拓扑序列就是原图的逆拓扑序列。
