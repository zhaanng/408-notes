**查找数据**：
依据 查找数据的地址 **最终指向没有数据的地址** 表示 查找数据不在哈希表中 ，有一个BUG。
	当 哈希表全部存满数据 时，即使 要查找的数据不在哈希表中，也 **不会出现指向空地址** 的行为——因为我们查找的地址范围限制在 1~n n为存入的数据个数，及**不会超出哈希表的范围**。
如何修复？
	1、加入一个判断，确保查找的地址 **不会再转回最开始的地址** ，即找了一圈都没有找到，这时就是在表中不存在。
	2、统计查找次数，确保它小于 **最大查找次数**。

#include<stdio.h>
#include<stdlib.h>
#define size 15
#define nul -1
//表长为m，n个数据构造散列表，保证n<=m 且表中数据均为非负整数
//Hash(key)=key%13
//处理冲突的方法：线性探测法
typedef struct
{
	int* data;//哈希数组
	int m;//表长m
}HashTable;
HashTable* CreateH()
{
	HashTable* h=(HashTable*)malloc(sizeof(h));
	h->data=(int *)malloc(sizeof(h));
	h->m=size;//表长为size
	for(int i=0;i<h->m;i++)
	{
		h->data[i]=nul;
	}
	return h;
}
int Hash(int k)
{
	return k%13;
}
int Findadd(HashTable* h,int k)
{
	int i=Hash(k);//计算哈希地址
	int d=0;
	while(h->data[i]!=nul)
	{//i位置冲突 则线性探测计算新地址
		d++;
		i=(Hash(k)+d)%(h->m);//线性探测计算新地址

	}
	return i;
}
void Insert(HashTable* h,int k)
{
	int i=Findadd(h,k);
	h->data[i]=k;
}
void Findk(HashTable* h,int k)
{
	int i=Hash(k);
	if(h->data[i]==nul)
	{
		printf("不存在\n");
	}
	else
	{
		int newi=i,d=0;
		do
		{	
			if(h->data[newi]==k)
			{
				printf("%d\n",newi);
				return;
			}
			d++;
			newi=(i+d)%(h->m);
		}while(h->data[newi]!=nul&&newi!=i);
		printf("不存在\n");
	}


}
int main()
{
	int n,k;
	HashTable* h=CreateH();
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&k);
		Insert(h,k);
	}

	scanf("%d",&k);
	Findk(h,k);
	return 0;
}

**==红黑树==**：基于二叉树, 表达并实现**2-3-4树(2-3树)**的数据结构。
	就是B树，但是是 二叉树 实现2-3-4树 的形式。

3阶/4阶 B树 转换成红黑树：**按序拆分 添加颜色**

3阶/4阶 **B树**，找到有多个数据的结点，结点中只保留一个数据，其余都变成其子结点，**原先的子结点**跟在被分裂出去的结点的下面，
把给这些被分裂出去的结点涂成**红色**，原先的没动的结点涂成**黑色**，
这样就形成了一棵 **红黑树**

为什么要==**涂色**==？
	因为通过不同颜色的区分，我们把分裂的过程记录下来了，
	这样就可以实现从红黑树——》B树的转换了。
	**红色**表示被 父亲结点 分裂出来，所以只需要将红色结点的数据 **添加到其父亲结点的数据域**后，红色结点的子结点再 **做回父亲结点的子结点**。

在B树这，叶子结点有了个==新的概念==：
	**内部终端结点**：没有孩子的结点
	**叶子结点**：也叫**失败结点**，内部终端结点的空孩子，空结点
	也就是之前的 叶子结点 的概念现在变成了 内部终端结点 的概念。

红黑树的==性质==：结点有颜色 黑色或红色
	1、**根结点**一定是黑色结点
	2、**叶子结点**一定是黑色结点
	3、**不存在相邻的两个红色结点**（即 红色结点的孩子和父亲一定是黑色的）
		**2个**数据的结点拆分，把右边的拆分成**右子结点**，符合性质3
		**3个**数据的结点拆分，把左右两侧的数据拆分成**左右子结点**，只保留中间数据做父亲结点，符合性质3
		拆分后 所有结点都只有一个数据，不会进行二次拆分
		因此 性质3 恒成立
	4、对于每个结点，从该结点到其下面任意一个叶子结点的简单路径上，所含的**黑色结点**的数目相同。——》**因为B树绝对平衡**
		B树绝对平衡，所以从B树上任意结点，到达任意叶子结点的简单路径，**经过的结点数相同**，
		而转换成红黑树后，路径可能增加的路程是 经过红色结点，而红色结点又不计入这里的数目，
		所以说经过的黑色结点的数目相同
	5、顺序性。——可以看作有颜色的**二叉排序树**
		按中序遍历（左根右）输出，可以转换成 有序数列

==性质：左根右 根叶黑 不红红 黑路同==
