KMP算法：字符串匹配
全称：
	Knuth–Morris–Pratt algorithm
	---
	Donald Knuth（唐纳德・克努特）
	James H. Morris
	Vaughan Pratt
按功能特征命名：
	**Linear-Time String Matching Algorithm** 线性时间字符串匹配算法

-----------------------------------------
各种概念：

字符串：由0个或者多个字符组成的连续序列，称为字符串。串中字符的个数称为字符串的长度。

字符串和字符数组在C/C++语言里不一样。

C/C++：
	字符串最后一个默认的结束字符'\0'
	结束字符不算入长度。

==字符串==：s="abcd";
==字符数组==：c\[5]={'a','b','c','d'};

==子串==：一个字符串中，连续的一段字符序列，称为该串的一个子串。
	最短的子串是空串，长度为0
	最长的子串是字符串本身

ababdabab
"a"
"ab"
"aba"
"abab"
...
"ababdaba"

==前缀子串==：从字符串的第一个字符开始，到后面的任意一个字符结束（结束位置不能是最后一个字符），该范围内的字符组成一个前缀子串。
	不能为空，不能为本身。
	长度为n的字符串的前缀子串有n-1个。

ababdabab
"babdabab"
"abdabab"
"bdabab"
...
"b"

==后缀子串==：除第一个位置以外，从其他任意一个位置开始到最后一个位置结束，该范围的字符组成的是一个后缀子串。

前后缀子串可能相等，比如“aaaaaaa”

各种操作：

字符串匹配：给两个字符串s p，其中s为主串，p为==模式串==，要在主串中找到模式串。（即模式串是否为主串的一个子串）
	模式串 Pattern String
	主串 Text String

s="ababab"
p="bab"

1、BF算法：Brute Force String Matching Algorithm, 暴力匹配
	从主串的每一个位置开始 都与模式串匹配一次 直到匹配完毕或者每次都匹配不上为止。
	时间复杂度 O(n\*m)——》(n-m)\*m取量级是n\*m

2、KMP算法：时间复杂度O(n+m)
完全听不懂

```c++
#include<stdio.h>
#include<stdlib.h>
#include<string.h>
//KMP：时间复杂度O(n+m) n是主串的长度 m是模式串的长度
//默认0下标存储字符串
int main()
{
	char p[105];//主串
	char s[105];//模式串
	int next[105];
	scanf("%s",p);
	getchar();
	scanf("%s",s);
	
	int pl=strlen(p);
	int sl=strlen(s);
	if(pl<sl)
	{
		printf("-1\n");
	}
	else
	{
		//先算next数组
		next[0]=-1;
		next[1]=0;
		int x=0,j=2;//x是next[j-1]的值 就是next[1]
		while(j<sl)
		{
			if(x==-1||s[x]==s[j-1])
			{
				next[j]=x+1;
				x++;j++;

			}
			else x=next[x];
		}
		for(int i=0;i<sl;i++)
		{
			printf("%d ",next[i]);
		}
		printf("\n");

		//KMP匹配
		int i=0;
		j=0;
		while(i<pl&&j<sl)
		{
			if(j==-1||p[i]==s[j])
			{//匹配上
				i++;
				j++;
			}
			else
			{//失配
				j=next[j];
			}
		}
		if(j==sl)
		{
			printf("%d\n",i-j);
		}
		else printf("-1\n");

	}
	return 0;
}
```
