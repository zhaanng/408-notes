交换排序：基于 ==比较&交换== 思想的排序

==一==、

冒泡排序：假设对n个数排序，数据放到数组a中。a\[1]\~\~\~a\[n]
一开始：全是乱序区

随着排序的进行，乱序区减小，有序区增大

最终：全部是有序区

冒泡排序的思路：直接应用比较&交换的思想，对相邻的两个数据(a\[j],a\[j+1])两两比较，如果a\[j]<=a\[j+1]，不动；如果a\[j]>a\[j+1]，交换两者。

执行过程：需要执行n-1趟排序
每一趟排序，都对乱序区中的数据进行比较&交换：
	对相邻的两个数据(a\[j],a\[j+1])两两比较，如果a\[j]<=a\[j+1]，不动；如果a\[j]>a\[j+1]，交换两者。
	==**乱序区最大数就放到了乱序区的最后一个位置，此时该位置变成有序区**==。
或者从后往前倒序比较，把小数往前放。

优化：
	每次遍历乱序区，==**至少**==使一个最大值有序。
	因此，存在情况，不需要将所有的元素遍历

==时间复杂度==：
	不优化版：O(n^2)
	优化版：最好：==O(n)==  最差：O(n^2)

#include<stdio.h>
#include<stdlib.h>
int n,a[105];
//冒泡排序：时间复杂度O(n^2) 稳定的 就地的  空间复杂度O(1)
//不优化：最好 平均 最坏时间复杂度是O(n^2)
//优化： 最好的情况下 时间复杂度O(n)   平均 最坏时间复杂度是O(n^2)
int main()
{
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	int t;
	int flag=0;//标记也没有进行交换操作-----》这一步是优化
	for(int i=1;i<=n-1;i++)//枚举排序的趟数
	{
		//把乱序区的数据 从前往后 两两比较交换
		//乱序区[1,n-i+1]
		flag=0;//注意 m每趟开始前都得初始化————》这一步容易忘
		for(int j=1;j<=n-i;j++)
		{//比较a[j]和a[j+1]
			if(a[j]>a[j+1])
			{
				flag=1;
				t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}
		}
		if(flag==0)break;
	}

	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	return 0;	
}

void swap1(int &x, int &y)
{
	int tmp = x;
	x = y;
	y = tmp;

void BubbleSort(int a[],int l,int r)
{
	int count;// 优化：计数交换次数，如果有一次循环里count==0,则以后的循环里count==0恒成立，所以直接退出所有循环即可。
	int n = r - l+1;// 元素个数
	// n-1次遍历
	for (int i = 1; i <= n-1; i++)
	{
		count = 0;//每次循环前 count==0;
		int k = n - i;
		for (int j = 1; j <= k; j++)
		{
			if (a[j] > a[j + 1])
			{
				swap1(a[j], a[j + 1]);
				count++;
			}
		}
		if (count == 0)return;// 出现即停止程序
	}
}

==**二**==、
快速排序：基于==分治==思想 是==不稳定==排序
在待排序的数据中，选一个做基准数p，经过一趟排序之后把比p小的 交换到p前面； 把比p大的 交换到p后面。

经过一趟排序之后，p处在最终位置（p有序），并且比p小的都在前面。比p大的都在p后面。==整体有序了==。

对\[l, r]排序
基准数p的选取：选方便使用、
（1）选取待排序区间的==第一个==位置的数a\[l] 做基准数
（1）选取待排序区间的==最后一个==位置的数a\[r] 做基准数
（1）选取待排序区间的==中间==位置的数a\[(l+r)/2] 做基准数

p=a\[l]：采用插空法，选取合适的数据填补空位即可。

过程：
	![[Pasted image 20260426110017.png]]
	插空法：（以 p=数组\[l] 为例）数组范围：\[l,r]
		确定好p后，我们要做的就是 在==原地==（不额外开辟空间） 实现把\<p的放到p前面，\>p的放到p后面，要怎么做呢？==插空法== ==递归==
			1、我们可以先想一下，按照要求完成后会是什么样子。一定是p找到了他在整个数组中的合适的位置，即 \<p的在p前面，\>p的在p后面，这样意味着后续不会再需要处理p的位置，即p找到了最终所在的位置，那意味着接下来只需要再==分别==处理p左右两端的顺序即可。
			2、插空法是指，p所在的数组位置认为是空，用i j分别从l向右 r向左，假设从j向左==开始==，遍历数组找到第一个\<p的值\[j]，将\[j]和\[p]值==交换==，再是i向右遍历，找到第一个\>p的值\[i]，将\[i]和\[p]交换，==如此循环==，直到i j相遇，i\==j，此时说明已经实现 \<p的在p前面，\>p的在p后面，就将p放到现在的i j位置，**这个位置就是p最终的位置，是对p来说的有序位置**。
			3、如何实现这种循环？while(i<j){ while(p>\[j]) j--;swap(p,\[j]) ;while(p<\[i]) i++;swap(p,\[i]) ;} 这样就可以实现。

==时间复杂度==：
	最好O(nlogn) ——每次恰好平分 需要分logn次
	最差O(n^2) ——每次都分为1和其他 需要分n次

#include<stdio.h>
#include<stdlib.h>
//快速排序：选取待排序区间的第一个位置的数a[l] 做基准数
//时间复杂度：最好和平均时间复杂度是O(nlogn). 最坏情况是O(n*n)
//不稳定
//就地排序，空间复杂度：最好O(logn). 最坏O(n)
void QSort(int a[],int l,int r)
{//对a数组的下标[l,r]排序
	
	if(l>=r) return;//递归出口
	int i=l,j=r;
	int p=a[l];//选取待排序区间的第一个位置的数a[l] 做基准数
	while(i<j)
	{
		//a[i]位置空的，用j从后往前找小于p的数补过去
		while(i<j&&a[j]>=p)j--;//跳过大于等于p的数 找小于p的数
		if(i<j)
		{//此时a[j]<p 补到a[i]
			a[i]=a[j];
			i++;
		}
		//a[j]位置空的，用i从前往后找大于p的数补过去
		while(i<j&&a[i]<=p)i++;
		if(i<j)
		{//此时a[i]>p 补到a[j]
			a[j]=a[i];
			j--;
		}
	}
	//i==j
	a[i]=p;//基准数放到自己的位置
	QSort(a,l,i-1);
	QSort(a,i+1,r);
}
int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	
		QSort(a,1,n);
	

	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");

	return 0;	
}

#include <iostream>
using namespace std;

/*
快速排序 Qucik Sort
思路：
	1、基准数：选取每个区间第一个数作为基准数p
	2、插空法：完成一个数的位置的确定
	3、递归：完成所有数的位置的确定
*/
void QuickSort(int a[],int l,int r)
{
	if (l >= r)return;//递归出口
	int p = a[l];// 基准数：数组最左侧，最小值的目标地
	int i = l, j = r;// 确定遍历范围
	while (i < j)
	{
		while (i < j && a[j] >= p)j--;//找到第一个小于p的a[j]
		if (i < j)
		{
			a[i] = a[j];// p所在位置换成当前的a[j]
			i++;// 此时i处数据
		}
		while (i < j && a[i] <= p)i++;
		if (i < j)
		{
			a[j] = a[i];
			j--;
		}
	}
	// 把基准数放到自己合适的位置
	a[i] = p;

	// 当前i==j,指向p的位置
	QuickSort(a, l, i - 1);//左边区间
	QuickSort(a, i+1, r);//右边区间
}
// 读取数组 区间[l, r]上的数据内容
void readArr(int a[], int l, int r)
{
	cout << "数组" << a << " 的数据内容为：" << endl;
	for (int i = l; i <= r; i++)
	{
		cout << a[i] << " ";
	}
}
int main()
{
	int a[105];
	int n; cin >> n;
	for (int i = 1; i <= n; i++)
	{
		cin >> a[i];
	}
	QuickSort(a, 1, n);
	readArr(a, 1, n);

	return 0;
}
