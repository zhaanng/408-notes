==我对递归的理解==：非常的关键


递归核心原理｜两类递归彻底区分（数据结构专用）

## 一、递归本质总纲

所有树递归，**只分两大类**，没有第三种：

- **查询型递归**：只要结果、不改结构 → ==`return 递归()`==
    
- **改构型递归**：修改结构、更新指针 → ==`本层指针 = 递归()`==
    

---

## 二、第一类：查询型递归（return 递归）

### 1. 写法

`return Find(子树, x);`

### 2. 执行逻辑

- 递归一直往下走，直到底层触发终止条件
    
- **底层的返回值，逐层原封不动向上传递**
    
- 最外层最终拿到的是：**最底层的结果**
    

### 3. 核心特点

- ✅ **不赋值、不修改任何指针**
    
- ✅ **完全不会破坏树结构**
    
- ✅ 返回值精准（目标节点 / NULL）
    

### 4. 适用场景

查找、求树高、统计节点数、判断平衡、遍历求值（所有**只读不修改**操作）

### 5. 标准示例（BST 查找）

```Plain
BSTNode* Find(BSTree root, int x)
{
    if (root == NULL || root->data == x)
        return root;
    if (x < root->data)
        return Find(root->l, x);
    else
        return Find(root->r, x);
}
```

---

## 三、第二类：改构型递归（指针接收递归）

### 1. 写法

`root->l = Insert(root->l, x);`

`root->r = Insert(root->r, x);`

### 2. 执行逻辑

- 下层递归返回节点/NULL
    
- **用下层返回值覆盖本层指针**（修改树结构）
    
- 执行完赋值后，**return 本层当前节点**
    
- 逐层向上返回「每层自身节点」，**最外层永远返回整棵树的根**
    

### 3. 核心特点

- ❌ **会修改树的指针、改变树结构**
    
- ❌ **无法返回底层结果，最终返回根节点**
    
- ✅ 专门用来新增、删除、重构树
    

### 4. 适用场景

BST 插入节点、删除节点、重建二叉树（所有**修改结构**操作）

### 5. 标准示例（BST 插入框架）

```Plain
BSTNode* Insert(BSTree root, int x)
{
    if (root == NULL)
        return CreateNode(x);
    if (x < root->data)
        root->l = Insert(root->l, x);
    else
        root->r = Insert(root->r, x);
    return root;
}
```

---

## 四、致命易错点（考试必坑）

### 错误：查找用了「改构型写法」

```Plain
// 绝对错误！！
if (x < root->data)
    root->l = Find(root->l, x);
return root;
```

**两大恶果：**

1. **破坏树结构**：会覆盖指针、清空子树
    
2. **返回值错误**：永远返回根节点，找不到目标节点
    

---

## 五、终极口诀（一秒判断写法）

- **只查不改 → 直接 return 递归**
    
- **要改结构 → 指针接收递归**
