一、==顺序查找==
	把数据集合存放在线性表中，从前往后（或者从后往前）顺序依次把每个数据的关键字进行比较，直接得出结果。
	在n个数据中查找k，第i个数据的查找长度是ci
	----------------------------
	ASL<sub>成功</sub>=(c1+c2+c3+...+cn)/n
	ASL<sub>失败</sub>=n+1
	----------------------------
	顺序存储 和 链式存储 均可

二、==折半查找==（二分查找）
二分思想：二分查找
前提：数据集合==有序==
假设查找数据k，带查找的下标范围是\[l, r]
二分查找：每次都和中间位置mid的数据进行比较，mid=(l+r)/2，向上/向下 取整

1、k\==a\[mid] 查找成功
2、k<a\[mid] 缩小查找范围, \[l, mid-1]
3、k>a\[mid] 缩小查找范围,\[mid+1,r]
如果一直找不到，查找范围会一直缩小，最终会使得==l>r==, 查找**失败**

ASL<sub>成功</sub>
ASL<sub>失败</sub>

**判定树**：一定是==平衡二叉树==
![[Pasted image 20260516191511.png]]

**任意一棵平衡二叉树 ==不都是== 一个二分查找对应的判定树**
原因：mid=(l+r)/2
	对于二分查找的判定树的塑造过程：
		都用的 mid=(l+r)/2 向下取整
		或者 mid=向上取整((l+r)/2.0) 向上取整
		这样产生的结点，是他 父结点 和 孩子结点 进行取mid 得到的，所以只会符合 向上取整/向下取整 ，不会既有 向上，又有 向下，向上向下==不可以==同时存在。
	而平衡二叉树没有这样的约束，向上向下==可以==同时存在。

![[Pasted image 20260516194653.png]]

判定树——》顺序存储
链式存储——》可以，但不适合——》ASL

代码：时间复杂度==O(logn)==
```c
#include<stdio.h>
#include<stdlib.h>
//折半查找：
int n,a[105],k;
int main()
{
	scanf("%d %d",&n,&k);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	int ans=-1;
	//折半查找:
	int l=1,r=n,mid;
	while(l<=r)//待查找区间中至少有一个数据 就继续进行查找----O(logn)
	{
		mid=(l+r)/2;//中间位置
		if(k==a[mid])
		{
			ans=mid;
			break;
		}
		else if(k<a[mid])
		{
			r=mid-1;//更新查找范围
		}
		else
		{
			l=mid+1;//更新查找范围
		}
	}
	
	printf("%d\n",ans);
	
	return 0;
}
```

代码：==自己写的==
```C++
#include <iostream>
#define maxx 105
using namespace std;

int num[maxx];// 顺序表存取数据
/*
	二分查找 Binary Search
	数据存储在 顺序表 中，即 数组 中
	对表中n个数据进行排序，确定初始left right middle
	怎样判断查找到 目标数据 了？
		当left==right，且 指向的数据 等于 目标数据
	怎样判断 目标数据 不在该表中？
		当left>right，此时说明 23 30 35，查找 34，再一次查找会指向30，
		但此时 和目标数据 不相等，两指针继续走，就出现left>right，则证明表中不存在
*/
// 参数：顺序表t[]，查询范围左边界l，查询范围右边界r，目标数据target
// 返回值：target在表中的下标
int BinarySearch(int t[], int left,int right,int target)
{
	int n = right - left;// 查询范围的数据个数n
	int l = left, r = right, mid;
	while (l <= r)
	{
		mid = (l + r) / 2;// 向下取整
		if (t[mid]==target)
		{

			cout << "数据 "<<target<< " 在下标 " << mid << " 位置" << endl;
			return mid;
		}
		else if (t[mid] < target)
			l = mid + 1;
		else
			r = mid - 1;
	}
	cout << target << " 不在表中" << endl;
	return -1;// 错误下标，表示不在表中
}

int main()
{
	int n; cin >> n;// 顺序表的数据个数
	int target; cin >> target;//读取要查询的目标数据
	for (int i = 1; i <= n; i++)
		cin >> num[i];// 存数据到顺序表中
	BinarySearch(num, 1, n, target);

	return 0;
}
```
