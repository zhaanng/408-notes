#### 进制之间转换

二进制转十进制：
	按权展开相加法：各位数码与权值相乘  再相加。
	小数的权值为 2<sup>-x</sup> 。
	(11011.101)<sub>2</sub> = 1* 2<sup>4</sup> + 1* 2<sup>3</sup> + 1* 2<sup>2</sup> + 1* 2<sup>1</sup> + 1* 2<sup>0</sup> + 1* 2<sup>-1</sup> + 1* 2<sup>-2</sup> + 1* 2<sup>-3</sup> = 27.625

十进制转二进制：

	小数部分：乘积取整法，积的“小数部分”为0时结束

并不是每个十进制小数都能准确的用二进制表示。
因为在转换过程中，可能乘积的小数部分总得不到0，即转换得到需要的位数后还有余数，这种情况下得到的是近似值。

### 浮点数的表示方式

对于小数，我们数学上定义了一些表示方法，比如科学计数法。

十进制：
科学计数法：
	一种将任意一个较大或较小的数简化表示的方法。
	它由两部分组成：尾数或指数
	例如：一个数x可以用以下形式表示。
	x = a * 10<sup>n</sup>

其中：
a称为“**尾数**”或“有效数字”，可以是正数也可以是负数，1<=|a|<10
n是整数，代表指数，用于指示小数点相对于a的位置移动了多少位。

563.128=5.63128 * 10^2

注：一个采用科学计数法表示的数，若没有前导零且小数点左边只有一位整数，
则可以称为 规格化（normalized）数

例如：1\*10^(-9) 就是规格化的科学计数，但0.1\*10^(-8) 和 10.0\*10^(-10)就不是。

定点数的编码表示：原码  反码  补码  **==移码==**

==移码==：常用来表示浮点数的阶码。
移码就是在真值X上加上一个常数（偏置值），通常这个常数取2^n ，相当于X在数轴上向正方向偏移了若干单位，这就是“移码”一词的由来。

n位移码，偏置值位2^(n-1)

例如：8位移码，第一位还是符号位，偏置值2^7

10101<sub>2</sub>  的移码：10101+1000 0000 = 1001 0101
-10101<sub>2</sub>  的移码：（-10101）+1000 0000 = 0110 1011

n+1位移码的特点：
1、零的表示唯一：\[+0]<sub>移</sub> = 2<sup>n</sup>+0=100...00    \[-0]<sub>移</sub>=2<sup>n</sup>-0=100...00 (n个0)
2、一个真值的移码和补码仅差一个符号位，所以 \[x]<sub>补</sub>的符号位取反得到\[x]<sub>移</sub>
	所以在 原反补码中“0正1负”；移码中“0负1正”。
3、移码全0时，对应真值的最小值-2<sup>n</sup>；移码全1时，对应真值的最大值2<sup>n</sup>-1。
4、移码保持了数据原有的大小顺序，移码大真值就大，移码小真值就小。
