Prim算法求最小生成树：

给定一个带权无向连通图：该图中含有n（10<=n<=100）个点，m条边，n个点的数据刚好是0\~~n-1,保证边权最大数10000.
求该图的==最小生成树==：从m条边中，选出n-1条边，使得图**连通**并且**边权和最小**。
输出最小生成树的边权和。

从选点的角度来分析：从一个点开始，用n-1条边把剩下的n-1个点连到生成树上，只要每条边都能连一个新点到生成树，最终必然是==无环的树形结构==。

把点分成两类：
	1、已经加入到生成树中的点。
	2、还没加入到生成树中的点。

![[Pasted image 20260411224821.png]]

**定义**：点x到生成树的距离为dist：点x到生成树中的某些点之间 的边的边权，其中最小的边权就是点x到生成树的最小距离。
dist\[x]=w 当前，点x到生成树的最小距离w
在构造过程中，随着最小生成树的扩大，dist\[x]可能会==变得更小==
 
 初始化 dist\[]=∞
 1、任选一个点x，加入到生成树中dist\[]=0；
 2、进行循环，循环n次。每次选一个dist值最小的并且还没有加入到生成树中的点p，通过一条边加入到生成树中。
 更新p的邻接点j到生成树的最小距离 dist\[j]=min(dist\[j].p---w--j)

代码思路：
	初始化dist\[]=∞ flag\[]=0 标记作用
	1、任选一个点x，加入到生成树中 dist\[x]=0；
	2、循环 n次：（1）选flag\[]\==0&&==dist\[]最小的点p（贪心，局部最优）== 加入到生成树中
	（2）flag\[p]=1
	（3）更新p到邻接的点的dist值

Prim算法每次只保证局部最优，那么它是否能够实现全局最优？
	答案是 ==可以==。
证明Prim 算法的**正确性**：
	无向带权连通图一定有最小生成树。
	--------------------------
	假设 通过最朴素的手推的方式找到了一棵最小生成树 Y。
	--------------------------
	假设通过Prim 算法构造的最小生成树是Yp
	----------------------
	1、如果恰巧Yp和Y完全一样，Yp也一定是最小生成树
	2、如果Yp和Y不完全一样（存在一样的地方）：Yp和Y至少有一条边不一样，可以证明，==Yp的每一条边 都可以再 Y中找到边权相同的边==。
	-
	按照Prim 算法的流程进行。
	最极端的情况，每一条边都不一样。
	-通过证明 得出Yp中每一条不一样的边 都可以在Y中找到边权相同的边，Yp和Y边可能有不同，但是边权都是相同的，因此Yp一定也是最小生成树。

	左边是Prim 算法 找到的最小生成树 Yp，右边是手推的最小生成树 Y；
	因为Prim是选距离最近的不在生成树上的点，因为选a-b不选a-c，所以a-b距离x <= a-c距离y，
	而Y是最小生成树，==把Y树看作 b-c边所在的生成树去找a点==，为使总边权最小，也要选边权最小的边（和Prim一样），因为它选择了a-c而不选a-b，所以a-c <= a-b，
	由两个贪心思路可知，==只有a-b == a-c时，可使两值同时成立==。

	#include<stdio.h>
#include<stdlib.h>
#include<string.h>
#define INF 10001
//给定一个带权无向连通图，该图含有n(<=100)个点，m条边。要求 找到该图的最小生成树，输出最小生成树的边权和。n个点的数据0～～n-1。边权都小于10000
//邻接矩阵
int n,m;
int dist[105];
int flag[105];
int g[105][105];
int min(int a,int b)
{
	return a<b?a:b;
}
void Prim()//时间复杂度O(n^2)
{
	int s=1;//任选一个点加入到生成树中
	dist[s]=0;//保证第一个选的点一定是起点
	int minn;//保存dist最小的点
	int t;//保存dist[minn]
	int sum=0;
	for(int i=1;i<=n;i++)//枚举循环次数
	{
		//1.找flag==0并且dist最小的点
		t=INF;
		minn=-1;
		for(int j=0;j<n;j++)
		{//枚举所有的点 找flag==0并且dist最小的点
			if(flag[j]==0&&dist[j]<t)
			{
				minn=j;
				t=dist[j];
			}
		}
		//minn 加入到生成树中
		printf("点%d 通过边权为%d 到边,加入到生成树中\n",minn,t);
		flag[minn]=1;//标记
		sum+=t;//算边权和
		//更新minn的未加入到生成树中的邻接点的dist值
		for(int j=0;j<n;j++)
		{
			if(flag[j]==0&&g[minn][j]<INF)
			{
				dist[j]=min(dist[j],g[minn][j]);
			}
		}
	}
	printf("最小生成树的边权和为%d\n",sum);

}
int main()
{
	scanf("%d %d",&n,&m);
	//先初始化邻接矩阵和dist数组
	for(int i=0;i<n;i++)
	{
		dist[i]=INF;
		for(int j=0;j<n;j++)
		{
			g[i][j]=INF;
		}
	}
	int x,y,w;

	for(int i=1;i<=m;i++)//O(m)
	{
		scanf("%d %d %d",&x,&y,&w);
		g[x][y]=g[y][x]=w;
	}
	Prim();
	

	
	return 0;
}
