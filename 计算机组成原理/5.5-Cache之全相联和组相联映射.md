#### 二、3、组相联映射 Set Associative

组相联 Set Associative 缓存设计是直接映射和全相联映射之间的一个折中方案，
他试图平衡二者的优势，既减少冲突缺失，又避免全相联映射的高硬件复杂度和成本

==**组件采用直接映射，而组内的块之间则采用全相联映射**==
