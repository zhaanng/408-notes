内存存储的==物理机制==
	VCC : Voltage Common Collector-Power Supply Pin ==电源引脚==
	A0~A9 : Address ==地址引脚==
	RD : Read ==读取引脚==
	WR : Write ==写入引脚==
	D0~D7 : Data ==数据引脚==
	GND : Ground ==地引脚==

图中的这种内存电子元件，最多能**同时**存储多少内存呢？
	该元件一个，只能存储 8bit
	不断叠加，通过用不同的地址来标记，最多可以叠加 2^10 个
	也就是最多也叠加出 8\*2^10 bit 的数据，也就是 1024 Byte，也就是 1 KB。
	如果地址信号引脚增加到==32==个，那么最多可以存储 8\*2^32 bit = 8\*2^10\*2^10\*2^10\*2^2 = 1 KB \*2^10\*2^10\*2^2 = 1 MB \*2^10\*2^2 = 1 GB \*4 = ==4 GB==
