特殊的队列：
	双端队列：两端均允许入队操作和出队操作，特点是灵活。

不分队首和队尾

左侧入队出队，右侧入队出队。
通过四种操作的搭配，可以搞一些特殊的结构
例如：
	左边入队的数据必须从左边出队。右边入队必须从右边出队。

基于顺序存储结构实现双端队列---循环数组 data\[xxx] 左端“指针”l 右端"指针"r 

初始化： l=0 r=0
左端入队：数据k左端入队
	如果认为 l指向真正的左端数据 l=(l-1+maxx)%maxx, data\[l]=k;-------------------方法1
	如果认为 l指向真正的左端数据的前一个位置 data\[l]=k, l=(l-1+maxx)%maxx;------2
右端入队：数据k右端入队
	如果认为 r指向真正的右端数据 r=(r+1+maxx)%maxx, data\[r]=k;-------------------3
	如果认为 r指向真正的右端数据的前一个位置 data\[r]=k, r=(r-1+maxx)%maxx;------4
	![[Pasted image 20260125195046.png]]
	只有方法1，4和方法2，3两种解法，这样才能实现双端队列。1，3和2，4不能实现，自己画图试一下。
左端出队：l = (l+1)%maxx; sum--;
右端出队：r = (r-1+maxx)%maxx; sum--；
判满判空：
	三种方法；
	这里引入一个变量sum记录队列中的数据的个数
	if(sum == 0) 空;
	if(sum == maxx) 满;

基于链式存储结构实现双端队列-----双向链表

初始化：创建一个带头结点的空的双向链表，l r都指向头结点

认为 l指向真正的左端数据，认为 r指向真正的右端数据后一个位置

左端入队：新建一个结点s，s->data=k,s插入到l的前面
右端入队：r->data=k,新建一个结点s, s插入到r后边，此时s中是脏数据

左端出队：把 l指向的结点free掉
右端出队：把 r指向的结点free掉

判空：l == r
