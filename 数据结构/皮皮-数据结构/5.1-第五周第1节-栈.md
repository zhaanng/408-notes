栈（Stack) -- 线性逻辑结构

1.线性表：
	一对一的线性逻辑结构，可以在任意位置执行任何操作
2.栈：
	是只允许在一端进行删除或者插入操作的线性表。并且没有查找和修改操作。

术语/概念：
	栈顶（Top）：
		允许执行删除or插入操作的一端
	栈底（Bottom）：
		不允许执行删除or插入操作的一端。
	空栈：
		不含任何数据。

性质：
	先进后出/后进先出

应用场景：
	1.函数的调用的实现（递归）
	2.业务需求：一些倒着走的逻辑，历史记录、撤销。。。
	3.物理上的堆栈

操作：
	初始化一个栈
入栈：
	往栈顶放一个数据
出栈：
	删除栈顶数据
判满
判空
得到栈顶元素（get）

栈的顺序结构实现：
	栈的范围：
		栈顶到栈底的范围（数组的大小不是栈的大小）
	基于顺序存储结构实现：顺序栈-----基于数组实现 a\[max];
	根据栈顶含义的不同，有两种实现方法：
		（1）栈顶标记真正的栈顶数据：
			初始化：
				声明一个数组，同时把栈顶==top“指针”==赋值为-1（不是真正的指针类型，而是int，但有指针的作用）（数组的int下标有指针的作用）
			入栈：
				把数据k入栈，（top++，a\[top] = k;)
			出栈：
				top--;
			判满：
				栈不会满，但给顺序栈开辟的连续空间会被栈充满；
				栈有没有充满数组，top == max-1;
			判空：
				top == -1;
			get栈顶元素：
				先判空，非空时，return a\[top];
		（2）栈顶标记真正栈顶数据的下一个位置：
			初始化：
				声明一个数组，同时把栈顶“指针”top(本质上是下标)赋值为-1.
			入栈：
				先判满，把数据k入栈 a\[top] = k, top++;
			出栈：
				先判空，top--；
			判满：
				栈有没有充满整个数组 top == max;
			get：
				先判空，非空时， return a\[top-1];

基于链式存储结构（带头结点的单链表）实现：
	链式表：
		栈顶指针：
			头指针，靠近头结点这边是栈顶。尾结点是栈底。
		初始化：
			声明一个带头结点的空链表
		入栈：
			头插法
		出栈：
			先判空，删除首元结点
		判空：
			top->next == NULL；
