==一、选择排序==
	基于选择的排序
	==不稳定==排序
	时间复杂度：==O(n^2)==
	==就地排序==
	![[Pasted image 20260428085644.png]]
	共n个元素,两种排序方向，**第i次**遍历**乱序区**——a\[i]~a\[n]或者a\[n-i]~a\[1]，找到其中**minn/maxx**，和 正数第i个元素/倒数第i个元素 交换值，经过n-1次遍历，完成排序。

==改进==：
	内层遍历乱取找最小值可以改进，由O(n)变成O(logn)，==堆排序==可以实现。

代码：
```
#include<stdio.h>
#include<stdlib.h>
//选择排序：不稳定  时间复杂度O(n^2) 就地排序。空间复杂度O(1)

int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	
	int minn=0,t;//保存最小的数的下标
	for(int i=1;i<=n-1;i++)//枚举排序的趟数
	{
		//第i趟排序，在乱序区中找到最小的数 ，交换到乱序区的第一个位置
		//乱序区[i,n].  乱序区中最小的数 和a[i]
		minn=i;//一开始假设i位置最小，后面遍历更新
		for(int j=i+1;j<=n;j++)//遍历乱序区找最小值
		{
			if(a[j]<a[minn])
			{
				minn=j;
			}
		}
		//a[i]和a[minn]交换
		t=a[i];
		a[i]=a[minn];
		a[minn]=t;

	}

	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	
	return 0;
}
```

```
#include <iostream>
using namespace std;

/*
选择排序 Selection Sort：默认 从小到大 排序
	元素分为：有序区 乱序区
	遍历乱序区，最次遍历找到 minn/maxx，放到有序区 最前/最后
	1、找minn
		有序区在前，每次遍历找乱序区中minn，因为有序区的值都是之前遍历的minn，所以每次乱序区找到的minn
		都是 >= 有序区最大值的，可以直接放到有序区最后。
	2、找maxx
		有序区在后，每次遍历找乱序区中maxx，因为有序区的值都是之前遍历的maxx，所以每次乱序区找到的minn
		都是 <= 有序区最小值的，可以直接放到有序区最前。
*/
// 找minn
void selectionSort(int a[],int l,int r)
{
	// minn：记录最小值的下标；t：中间完成值交换的缓冲区；n：数据要排序的元素个数
	int minn,t, n = r - l + 1;
	for (int i = l; i <= r-1; i++)
	{
		minn = i;
		for (int j = i+1; j <= r; j++)
		{
			if (a[minn] > a[j])
			{
				minn = j;// 保存最小值的 下标
			}
		}
		// 交换a[i]和a[minn]
		t = a[i];
		a[i] = a[minn];
		a[minn] = t;
	}
}
```

==二、堆排序==
	基于选择的排序
	==选择==的思想：每次在乱序区中找到最小的数据，放到乱序区的第一个位置。执行一次之后 乱序区缩小，有序区增大。每次可以确定一个数据的位置，对n个数排序，执行n-1趟

堆：基于==”**完全**“==二叉树的树形结构。直接用==**数组**==存堆
并且满足：
	在**完全二叉树**的基础上 规定：父亲结点的值要大于孩子结点的值——》大顶堆/大根堆
	在**完全二叉树**的基础上 规定：父亲结点的值要小于孩子结点的值——》小顶堆/小根堆

==为什么==要求是在 完全二叉树 基础上：
	数组存 非完全二叉树时，会浪费空间
	链表存取，读取树的操作会很麻烦
	综上，就采用 ==**数组存取的完全二叉树**== 来构建堆
	![[Pasted image 20260428170205.png]]

性质：
	大顶堆的堆顶是 ==值最大== 的值
	小顶堆的堆顶是 ==值最小== 的值

堆的操作：
	直接用数组存堆    a\[i]的父亲是a\[i/2]. 左孩子是\[2\*i]. 右孩子是\[2\*i+1]

1、根据给定的n个数据建堆——以建立大顶堆为例

n=8
53 17 78 9 45 65 87 32

==法一==：原地调整——**向下调整**
	由小子树向大子树调整
	依次 分别调整 以 a\[n/2]\~\~\~a\[1]为根的子树即可：
	采用向下调整法：从根结点，结点和孩子比较 最大的做父亲。直到结点没孩子 或者结点本身就是最大的值 为止。
![[Pasted image 20260428155917.png]]

计算向下建堆的时间复杂度O(n)：
	![[Pasted image 20260428164837.png]]
			h=logn

注意两个问题：
	1、为什么要从小子树往大子树调整？
	2、向下调整建堆的时间复杂度是==O(n)==, 而不是O(nlogn)，为什么？
		n个结点，树的高度h=\[logn]+1，向下取整+1
		向下取整调整整棵树到堆的==总次数N=n-h=n-logn==;时间复杂度取最高阶（最大级项） 则n>logn,得O(n)

向下调整 ==代码==：
```
#include<stdio.h>
#include<stdlib.h>
//堆排序：
void Swap(int *x,int *y)
{
	int t=(*x);
	(*x)=(*y);
	(*y)=t;
}
void DownAdjust(int a[],int i,int n)
{//向下调整
	int now=i;//当前结点
	int nex;//next：值最大的孩子
	while(2*now<=n)
	{//如果当前结点只是有一个孩子
		nex=2*now;//先让next指向左孩子
		if(2*now+1<=n&&a[2*now+1]>a[2*now])
		{//右孩子存在 且右孩子值更大
			nex=2*now+1;
		}
		if(a[now]<a[nex])
		{//父亲比孩子小 交换
			Swap(&a[now],&a[nex]);
			now=nex;//再继续向下调整
		}
		else
		{//如果父亲大 满足大顶堆 跳出 结束。
			break;
		}

	}

}
int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
		
	}
	//向下调整法 原地建堆
	//依次 分别向下调整 以 a[n/2]~~~a[1]为根的子树即可：
	for(int i=n/2;i>=1;i--)//枚举被调整的子树的根-----总的时间复杂度O(n)
	{
		DownAdjust(a,i,n);	//调整以a[i]为根的子树 调整为大顶堆
	}




	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	return 0;
	
}
```
