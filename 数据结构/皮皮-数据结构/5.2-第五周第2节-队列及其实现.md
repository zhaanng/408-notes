队列：
	只允许在一端进行插入操作，另一端进行删除操作的线性表。并且没有查找和修改操作。
队首：执行删除操作的一端
队尾：执行插入操作的一端
空队列：不含任何数据元素

性质：先进先出/后进后出

队首 “指针”
队尾 “指针”

1.队列的顺序存储：顺序存储---数组 maxx 7
	data\[maxx]
		队首指针 int f
		队尾下标 int r
		单向队列：
			（1）队尾指针指向真正的队尾元素
				初始化：
					f = 0 r = -1
				入队：
					r++,data\[r] = k;
				出队：
					删除队首指针指向的元素，f++
				判满：
					判断数组还能否容纳新数据。r == maxx-1（可能会出现==假溢出==情况）（即进队后又有出队，最后虽然数组最后空间也有元素，但数组最前面的空间里的元素已排出，仍有空间，但无法再进入元素）。---解决：循环队列
				判空：
					f == r+1（为空时，f == r+1；不为空时，元素全部出队后，f指向将要出队的元素，即r指向元素的下一个元素，也是f == r+1）
			（2）队尾指针指向真正的队尾元素的下一个位置，r-1是真正的队尾
				初始化：
					f = 0 r = 0;
				入队：
					data\[r] = k, r++;
				出队：
					删除队首指针指向的元素，f++
				判满：
					判断数组还能否容纳新数据。r == maxx（可能会出现==假溢出==情况）（即进队后又有出队，最后虽然数组最后空间也有元素，但数组最前面的空间里的元素已排出，仍有空间，但无法再进入元素）。---解决：循环队列
				判空：
					f == r（为空时，f == r；不为空时，元素全部出队后，f指向将要出队的元素，即r指向的元素，也是f == r）
		循环队列：
			通过数学上的取模运算实现循环，下标的首尾相接（实现的是 找要入队或出队的元素的下标时 自动在所有下标中循环）
			循环队列中，r不能真正的队尾元素，循环中无法实现指向-1，所以只能有让r指向真正的队尾元素的下一个元素的这种方法能实现循环队列。
				初始化：
					f = 0 r = 0;
				入队：
					data\[r] = k, r = （r+1)%maxx;
				出队：
					删除队首指针指向的元素，f = （f+1)%maxx;
				判满：
					判断数组还能否容纳新数据。
					会发现，按照之前的思路，在循环队列中，判满和判空的条件都是f == r，无法进行区分。
					要解决，有三种方法：
						1.初始化时加入count = 0；入队一个元素，count++，出队一个元素，count--；最后count == 0的话，为空，count == maxx的话，为满。
						2.引入一个标记变量flag = 0（初始化只能是0，默认进行了一次出队操作，否则无法进行入队操作【入队先判满】）；flag == 0，出队；flag == 1， 入队。判空用（flag == 0 && f == r)，判满用（flag == 1 && f == 1）。
						3.==牺牲一个空间==，数组中有maxx-1个数据时就满了
						f == (r+1)%maxx 为满
						f == r 为空
				判空：
					f == r（为空时，f == r；不为空时，元素全部出队后，f指向将要出队的元素，即r指向的元素，也是f == r）

2.队列的链式存储：链式队列---基于带头结点的单链表
	首元结点一侧是队首  尾结点一侧是队尾
	用头指针Node h做队首指针即可，此时队首指针指向真正队首的上一个结点
	队尾指针：指向尾结点的尾指针即可
	初始化：搞一个头结点Node head， 让队尾指针Node\* r 直接指向头结点即可
	入队：尾插法
	出队：判空，删除首元结点
	判空：队首指针和队尾指针指向同一个结点 f == r;
