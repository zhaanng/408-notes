==归并排序==：
	先把待排序的数据**一分为二**，从中间均分，把前后两部分分别排序，然后指向把两个有序序列 **合并**成一个有序序列的过程。
	前后两部分排序：**递归**。
	（特殊的，如果一分为二之后，其中一部分只一个数据，天然有序，不需要排序）


把两个有序序列 合并成一个有序序列----》==归并过程实现的排序==	
用两个指针i和j 从两个**序列开头**位置，依次**两两比较**，a\[i]和a\[j]中更小的一个是当前待排序数据中的最小值，把其放到有序序列中即可。最后当一个指针**越界**时，只需要把另一个序列中剩下的数据接到有序序列后面即可。
![[Pasted image 20260507112043.png]]
==递归==：
	**单个数据的列表自动有序**，
	递归把序列**划分**成多个单数据列表，再双指针**合并**序列。
	![[Pasted image 20260507113539.png]]

总时间复杂度==O(nlogn)== 因为不停二分，最后可以近似看作一棵完全二叉树，高度近似logn，每层遍历n个结点，所以共需要 nlogn 次。

代码：
```
#include<stdio.h>
#include<stdlib.h>
//归并排序：稳定  非就地  时间复杂度O(nlogn)
void MergeSort(int a[],int l,int r)
{//对a[l],a[r]进行排序
	if(l>=r)return;//递归出口
	//从中间位置均分,前一半[l,mid],后一半[mid+1,r]
	int mid=(l+r)/2;
	MergeSort(a,l,mid);//前一半排成有序的
	MergeSort(a,mid+1,r);//后一半排成有序的
	//	把两个有序序列合并成一个
	int i=l,j=mid+1;
	int t[105],k=0;
	while(i<=mid&&j<=r)
	{
		if(a[i]<=a[j])
		{
			t[k++]=a[i];
			i++;
		}
		else
		{
			t[k++]=a[j];
			j++;
		}
	}
	while(i<=mid)
	{//前面一半还没合并完
		t[k++]=a[i];
		i++;
	}
	while(j<=r)
	{//后面一半还没合并完
		t[k++]=a[j];
		j++;
	}
	//a[l]~~a[r]<------t[0]~~~t[k-1]
	for(int i=0;i<k;i++)//有序序列放回到原数组的原位置
	{
		a[l+i]=t[i];
	}

}
int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}

	MergeSort(a,1,n);
	
	
	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	return 0;
	
}
```

==计数排序==：
	![[Pasted image 20260514111754.png]]
基于统计的排序：计数排序 桶排序 基数排序

计数排序：
	直接统计每个数的个数，然后按数量输出。
	**时间复杂度：O(n+maxx)** n是总个数 maxx是最大数值
	==不能直接对 **负数 小数** 排序==
		负数处理：找到minn，取绝对值a，把数组所有值+a，后续输出时再 - 掉。
		小数处理：找到小数位最多的数，取小数位数为x，把所有值\*10^x,后续输出再 / 掉

过程：
	遍历数组num，创建一张minn~maxx的大表table，
	table\[num\[i]]++;//计数num\[i]的数的出现个数
	最后再遍历一遍大表table\[]，依次按次数输出对应值。
	==过程非常之暴力==，时间复杂度 空间复杂度都非常之低

如何使这个排序成==**稳定**==排序？
	![[Pasted image 20260515091843.png]]

代码：
```
#include<stdio.h>
#include<stdlib.h>
//计数排序:非就地   时间复杂度O(n+maxx)  稳定
//缺点：浪费空间
int n,a[105];//n<=100. 0<=a[i]<=10000
int cnt[10005];
int sum[10005];
int t[105],k;
int minn,maxx;
int main()
{
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	minn=maxx=a[1];
	for(int i=2;i<=n;i++)
	{
		if(a[i]<minn)minn=a[i];
		if(a[i]>maxx)maxx=a[i];
	}
	for(int i=1;i<=n;i++)
	{
		cnt[a[i]]++;
	}
	sum[0]=cnt[0];
	for(int i=1;i<=maxx;i++)
	{
		sum[i]=sum[i-1]+cnt[i];
	}
	for(int i=n;i>=1;i--)
	{//当前数a[i] 前面有sum[a[i]]个数
		k=sum[a[i]];
		t[k]=a[i];
		sum[a[i]]--;
	}


	for(int i=1;i<=n;i++)
	{
		
		printf("%d ",t[i]);
	}
	printf("\n");
	return 0;
	
}
```

==桶排序==：
	对n个数据排序，把n个数据分成若干组（桶），分组时保证桶间有序。然后对桶内分别排序，使得整体有序。
	灵活的算法，**先分桶，每桶内再单独排序**，无固定代码写法
	时间复杂度：**O(n+m\*plogp)** n总个数 m 分桶数 p每桶个数
	空间换时间

==基数排序==：
	以计数排序为基础，对数据的每个位数排序：由低位（个位）到高位
	保证 **稳定**排序
	时间复杂度：O(d*(10+n)) d是最大位数 n是元素个数
