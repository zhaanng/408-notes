动态规划 局限性：“==维数障碍==” ——》 降维 ==重要考点==

01背包：

背包问题：
有多种物品，每种物品有自己的**价格(价值)和重量(体积)**，有一个背包，背包可以装入物品，背包有一个重量（体积）的**上限C**，可以选择任意的物品放到背包中，在**不超过**背包重量上限的情况下，可以装入的物品的==**最大价值**==是多少。

多种物品，每种物品可以有多个。

根据每种物品有多少个以及选物品时是否有特殊规则 分为不同的类型：
	==01背包== 每种物品**只有一个**，即每种物品只有两种状态，被选中/没选中
	==完全背包== 每种物品**有无限多个**
	==多重背包==  每种物品**有多个，但有限**
	==分组背包== 物品**分多组**，每组物品**最多只能选择1个**
	。。。。
	共九种背包问题

动态规划：
1、确定是动态规划的问题
2、找状态数组：
状态数组：dp\[i]\[j]从前i个物品中选择若干个装入背包中，总重量不超过j的最大价值

问题是：
从n个物品中 选择若干个 装入到背包中，总重量不超过c，最大价值是多少？

转成陈述句:
从n个物品中 选择若干个 装入到背包中，总重量不超过c，最大价值是a。
dp\[n]\[c]=a

dp\[i]\[j]

3、初始状态 
dp\[0]\[j]=0
dp\[i]\[0]=0

中间状态
dp\[i]\[j]

最终状态
dp\[n]\[c]

4、状态转移方程
dp\[i]\[j]=max(v\[i]+dp\[i-1]\[j-w\[i]], dp\[i-1]\[j])

求中间状态法：

假设dp\[0]\[0]\~\~dp\[i]\[j-1]均已知，求dp\[i]\[j]
dp\[i]\[j]=max(v\[i]+dp\[i-1]\[j-w\[i]], 0+dp\[i-1]\[j])

5、写代码

-----=-----------------------------------

**动态规划，进行优化**：
数组降维——》只变数组的写法，**含义不变**
变成==滚动数组==

**红色是更新本次dp\[i]\[j]所用到的行
黄色是已经更新了的点**
![[Pasted image 20260625200046.png]]

这里注意，因为dp\[]\[]二维数组==降维==成一维数组dp\[]了，且现在的dp\[]存的是红色行的数据，而我们又在更新下一行的dp\[i]\[j]，所以是**在红色行的基础上进行==覆盖==更新**。
通过状态转移方程，我们能发现，ij需要的值是\[i-1]\[j-w\[i]]或者\[i-1]\[j],也就是**当前覆盖的点的 前面的点的数据**，所以我们在这里进行更新时，需要从一行的==后面==往前更新。
 

==代码：
有两种实现方法==：

时间复杂度过高的：
1、普通的暴力 ——优化——》加入 剪枝/记忆化搜索法
空间复杂度过高的：多维数组存储，无法处理大量数据
2、普通的动态规划 ——优化——》数组降维 变成 滚动数组
```C++
#include<stdio.h>
#include<stdlib.h>
int n,c;//n,c<=100
int v[105];//每个物品的价值
int w[105];//每个物品的重量
int maxx(int a,int b){return a>b?a:b;}
int dp[105];//状态数组：dp[rc]:从前i个物品种选择若干个装入背包中,总重量不超过rc的最大价值
//降维
int main()
{
	
	scanf("%d %d",&n,&c);
	//初始化：赋值初始状态。dp[0][j]=0 
	for(int i=1;i<=n;i++)
	{
		scanf("%d %d",&v[i],&w[i]);

	}

	for(int i=1;i<=n;i++)//从前往后求解更新
	{
		for(int j=c;j>=1;j--)//降维之后要倒着更新每一行
		{
			if(j>=w[i])
			{//如果能放的下 第i个物品 考虑选或者不选
				dp[j]=maxx(v[i]+dp[j-w[i]] , dp[j]);
			}
		
		}

	}


	printf("%d",dp[c]);

	return 0;
}
```
