## 使用说明

- 笔记使用 Obsidian 双链（`[[...]]`）与图片嵌入（`![[...]]`）语法，跨目录链接不受文件夹位置影响。
- 本仓库由本地 Obsidian vault 中的 `408考研/` 文件夹同步而来，图片随笔记一并保存。

## 更新方式

在 Obsidian 中编辑笔记后，双击仓库根目录的 `推送笔记.bat`，即可自动提交并推送到本仓库。
